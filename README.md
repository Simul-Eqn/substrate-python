## Substrate algorithm in python 

Code reference: [http://www.complexification.net/gallery/machines/substrate/](http://www.complexification.net/gallery/machines/substrate/) 

This is a Python implementation of the substrate algorithm 

- `substrate_s.pde.txt` is the reference p5js source code, from J. Tarbell 
- `palettes.py` contain sample colour palettes 
- `substrate.py` uses pygame to draw substrate (press `s` key to save image into a folder created based on time) it also draws not with black colour but with another colour 
- `postprocess.py` applies the bloom filter 
- `draw605.py` and `605_substrate.py` are guiding the crystal growth
